⚡ StudyBuddy — Student Productivity & Focus WebApp

A lightweight, zero-login, client-side productivity hub built for students. Features a full To-Do Task Manager, Pomodoro & Chess-Clock Style Study/Rest Timer, and an Academic Deadline Calendar with audio and visual reminder alerts.

🌟 Key Features

Zero Login / Instant Use:

Stores all data locally in your browser (localStorage).

Zero signup or account setup needed.

Built-in Export & Import (JSON) so you can backup your data or move it between devices anytime.

Pomodoro & Study/Rest Chess Clock:

Classic Pomodoro: 25m Focus, 5m Short Break, 15m Long Break with customizable minutes and quick-adjust +5m / -5m buttons.

Study/Rest Dual Clock: Inspired by chess clocks. Alternate between Study time and Rest time with a single click or spacebar.

Audio Chimes synthesized via Web Audio API (100% offline, zero audio file dependencies).

Dynamic tab title countdown (e.g. (24:50) StudyBuddy - Focus).

To-Do List:

Add tasks with academic subjects (Math, CS, Physics, etc.) and priority tags.

Filter by All, Incomplete, Completed, or High Priority.

Instant search bar.

Click "⏱️ Focus" on any task to instantly bind it to the Pomodoro timer.

Deadline Calendar & Reminders:

Interactive monthly calendar with event dots and date selection.

Upcoming deadlines list color-coded by urgency (Urgent < 48 hours, Soon, etc.).

Background audio and toast notifications when deadlines are approaching.
